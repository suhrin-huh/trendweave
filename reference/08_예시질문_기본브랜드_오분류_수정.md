# 예시 질문의 기본 브랜드 오분류 수정

작성일: 2026-10-21

## 현상과 원인

화면의 예시 질문은 특정 브랜드명 없이 런웨이·컬러·시장·브랜드 네 분야의 조사와 상품기획 방향 3개를 요청한다. 의도한 동작은 기본 브랜드 ZARA의 상품기획 분석 계획을 제안하고, 사용자 승인 후 네 분야를 조사하는 것이다.

실제 Gemini 분류 호출에서 다음 결과로 문제를 재현했다.

```json
{
  "domain_status": "fashion",
  "supported": false,
  "reason": "패션 트렌드 분석 및 상품기획 제안 요청으로, ZARA 브랜드에 국한되지 않은 일반적인 패션 시장 분석 및 기획 방향을 요구하고 있음."
}
```

패션 관련성은 통과했지만 지원 가능 여부가 false여서, 분석 계획 생성 이전에 `unsupported` 응답으로 종료됐다. 검색·보고서 작성 단계의 오류는 아니다.

기존 분류 프롬프트는 ZARA 상품기획만 지원한다고 설명하면서 **브랜드를 지정하지 않은 경우 기본 브랜드를 적용한다는 규칙을 전달하지 않았다.** 또한 질문의 「브랜드」가 조사 분야를 뜻한다는 구분이 없었다. 계획 생성 단계에서 ZARA를 선택할 수 있어도, 선행 분류에서 종료되므로 이 단계까지 도달하지 못했다.

## 수정

- 서버가 분류와 계획 생성에 `default_brand: ZARA`를 전달한다.
- 브랜드 미지정 일반 상품기획은 기본 브랜드를 적용하여 지원한다고 명시한다.
- 「런웨이·컬러·시장·브랜드」는 네 조사 분야이며 브랜드 비교 요청이 아니라고 설명한다.
- 브랜드를 기본 적용한 경우 계획의 가정에 표시하도록 한다.
- 명시적인 다른 브랜드 상품기획·브랜드 비교는 기존대로 미지원 안내를 유지한다.

질문에 ZARA라는 문자열을 덧붙이는 대신 분류 기준과 서비스 기본값 전달을 수정했다. 사용자 원문과 승인 흐름은 유지한다.

## 검증 방법

- 정확한 예시 질문으로 미리보기→승인 API 회귀 테스트를 추가했다. ZARA, 상품기획 유형, 네 조사 분야가 승인 요청에 저장되는지 확인한다.
- 실제 Gemini 미리보기 검증 스크립트 `scripts/verify_preview.py`에 같은 질문을 추가했다. `product_strategy`, `ZARA`, 네 분야를 모두 포함하는지 검사하며 검색·보고서 생성은 실행하지 않는다.

### 이번 실행 결과

- 전체 회귀 테스트: **61 passed in 16.70s**. 기존 비패션·미지원 요청 차단, 승인, 선택 조사, UI·PDF 검증을 포함한다.
- 수정 전 동일 질문의 `supported: false` 판정과 이유는 실제 Gemini 호출로 확인했다.
- 수정 후 실제 검증에서는 첫 번째 일반 상품기획 질문의 ZARA 미리보기 생성에 성공했다. 이어서 동일 예시 질문을 검증하던 중 Gemini 호출의 `GoogleAPIError`로 중단되어, 해당 질문의 수정 후 실제 응답은 아직 확인하지 못했다. 자동 회귀 테스트 성공과 실제 호출 성공은 구분한다.

실행 중인 서버를 재시작한 후 예시 질문을 다시 보내고, 제안 카드에서 상품기획·ZARA·네 분야를 확인한 뒤 승인한다.

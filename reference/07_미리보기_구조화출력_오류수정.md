# 미리보기 구조화 출력 오류 수정

작성일: 2026-10-21

## 원인

분석 계획을 생성하는 LLM에 최종 응답 모델 `PlanningSuggestion`을 직접 전달했다. 이 모델에는 서버가 정하는 `schema_version: 2`와 선행 관련성 판정 이후 확정하는 `domain_status: fashion`도 포함되어 있었다.

실제 LLM은 이 값을 각각 `1`, `pass`로 생성했다. LangChain의 Pydantic 파서가 고정값 검증에 실패하면서 `OutputParserException`이 발생했고, API는 미리보기 실패로 503을 반환했다. 이 로그의 503은 Gemini 서버 장애 응답이 아니라 애플리케이션의 출력 파싱 실패 응답이다.

## 수정

- `PlanningDraft`: LLM이 작성할 목적·유형·분야·시즌·방향만 포함한다.
- `PlanningSuggestion`: 검증된 초안에 서버가 버전 `2`, 패션 판정 `fashion`, 선행 판정 이유를 붙인 최종 응답이다.
- 모델이 요청하지 않은 버전·관련성 메타데이터를 추가해도 초안 파싱에서 제외한다. 최종 응답의 고정값 검증은 유지한다.
- 선행 `DomainDecision` 검사를 통과해야 계획 생성으로 진행하며 비패션 차단은 유지한다. 시즌·유형·분야 조합 검증도 유지한다.

변경 파일은 `agent/trendweave/review.py`, 모델 대체 테스트용 `tests/conftest.py`, 회귀 테스트 `tests/test_review.py`다.

## 검증

- 실제 LangChain `PydanticOutputParser`를 사용해 오류와 동일한 `schema_version: 1`, `domain_status: pass` 응답으로 미리보기 API가 200과 승인 가능한 제안을 반환하는지 확인했다.
- 최종 버전·관련성·판정 이유가 서버 값으로 저장되고, 미리보기만으로 작업이 생성되지 않는지 확인했다.
- 최종 모델의 잘못된 고정값, 초안의 잘못된 시즌·유형·분야는 계속 거절되는지 확인했다.
- 전체 테스트: `.venv/bin/python -m pytest -q` → **60 passed in 18.04s**. Chromium UI·PDF 회귀 테스트를 포함한다.
- 실제 Gemini 미리보기: `scripts/verify_preview.py`로 시즌 미지정 질문과 `2028 F/W` 명시 질문 **2건 모두 성공**했다. 응답의 `schema_version: 2`, `domain_status: fashion`도 확인했다. 검색·보고서 생성은 실행하지 않았으며 결과는 `.artifacts/live-preview.json`에 저장했다.

실행 중인 서버를 종료한 뒤 `./run.sh`로 재시작하고 분석 방향을 다시 요청한다. 모델 설정과 API 키 변경은 필요하지 않다.
